## 3. Function Signature

```python
def review_response(
    customer_complaint: str,
    company_policy: str,
    generated_response: str,
    api_key: Optional[str] = None
) -> dict:
```

### Parameters:
| Parameter | Type | Required | Description |
| :--- | :--- | :--- | :--- |
| `customer_complaint` | `str` | Yes | The customer's grievance text or inquiry. |
| `company_policy` | `str` | Yes | Store terms, return conditions, refund rules, and warranties. |
| `generated_response` | `str` | Yes | The initial draft response generated by Part 1. |
| `api_key` | `str` | No | Optional Gemini API key. If omitted, reads from `GEMINI_API_KEY` in `.env` or system environment. |

## 5. End-to-End Pipeline Integration Example

Below is a complete, production-ready example demonstrating how Part 1 should invoke Part 2:

```python
import os
from modules.response_reviewer import review_response

def handle_customer_inquiry(complaint_text: str, policy_text: str) -> dict:
    # -------------------------------------------------------------
    # Step 1: Part 1 generates the initial draft response
    # -------------------------------------------------------------
    # (Provided by Member 1)
    # initial_draft = generate_initial_response(complaint_text, policy_text)
    initial_draft = (
        "Hi! We are so sorry your coffee maker arrived with broken glass. "
        "Don't worry, we are sending you a replacement carafe right now!"
    )

    # -------------------------------------------------------------
    # Step 2: Part 2 audits and validates the draft response
    # -------------------------------------------------------------
    audit_result = review_response(
        customer_complaint=complaint_text,
        company_policy=policy_text,
        generated_response=initial_draft
    )

    # -------------------------------------------------------------
    # Step 3: Branching logic based on compliance audit
    # -------------------------------------------------------------
    compliance = audit_result["compliance_status"]
    
    if compliance == "Compliant":
        # Draft is safe to send directly
        final_message = initial_draft
    else:
        # Policy violations or false promises detected; use validated improved response
        final_message = audit_result["improved_response"]

    return {
        "status": compliance,
        "final_response": final_message,
        "violations": audit_result["policy_violations"],
        "false_promises": audit_result["false_promises"],
        "missing_info": audit_result["missing_information"],
        "tone_scores": audit_result["tone_scores"],
        "audit_mode": audit_result["analysis_mode"]
    }

# Example invocation
if __name__ == "__main__":
    complaint = "The coffee maker in order #4012 arrived with a broken carafe."
    policy = "Damaged items must be reported within 48 hours with order ID and photo proof before replacement."

    output = handle_customer_inquiry(complaint, policy)
    print(f"Compliance: {output['status']}")
    print(f"Final Output:\n{output['final_response']}")
```

## 6. Fault Tolerance & Deterministic Fallback

- **No API Key Required for Local Development**: If Member 1 does not have a Gemini API key configured, `review_response()` automatically switches to **Deterministic Local Validation Mode**.
- **Zero Crashes on Network Failure**: If an API call fails due to quota or network interruption, the function gracefully falls back to deterministic rule checks without raising unhandled exceptions.
- **Traceability**: The field `analysis_mode` indicates whether Gemini AI or the deterministic engine performed the review.
