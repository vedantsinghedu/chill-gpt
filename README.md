# ChillGPT — Customer Support Response Assistant

Welcome to the repository for **ChillGPT**, an AI-powered customer support response assistant.

This project is divided into two collaborating parts:
- **Part 1**: Customer Complaint Analysis and Initial Response Generation (Developed by Member 1)
- **Part 2**: Response Review and Policy Validation Module (Developed by Member 2 - Vedant)

---

## Part 2: Response Review and Policy Validation Module

The complete implementation of Part 2 is located in the [`ChillGPT-Reviewer/`](ChillGPT-Reviewer/) directory.

### Quick Start:

1. **Activate Environment**:
   ```bash
   source .venv/bin/activate
   ```

2. **Run Tests**:
   ```bash
   pytest ChillGPT-Reviewer/tests/ -v
   ```

3. **Launch Streamlit Interface**:
   ```bash
   cd ChillGPT-Reviewer
   streamlit run app.py
   ```

See [`ChillGPT-Reviewer/README.md`](ChillGPT-Reviewer/README.md) for full documentation, test execution results, and integration guidelines.
